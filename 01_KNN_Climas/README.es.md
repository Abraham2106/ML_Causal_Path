# 01: Clasificador de Clima con KNN

*Leer en: [English](README.md)*

## Resumen del Proyecto
El proyecto cubre el ciclo completo de clasificación supervisada: 
análisis exploratorio de datos (EDA), preprocesamiento, imple-
mentación manual de KNN en Python puro, comparación con
scikit-learn, y evaluación con métricas estándar.

## Objetivos Clave
- **Implementación Manual**: Programar la lógica de KNN (distancia euclidiana, votación de vecinos) sin librerías de ML de alto nivel.
- **Análisis Exploratorio de Datos (EDA)**: Procesar y visualizar el dataset UCI Weather AUS.
- **Evaluación del Modelo**: Medir el rendimiento usando Accuracy, Matrices de Confusión y Fronteras de Decisión.
- **KPI**: Alcanzar una exactitud (accuracy) de clasificación **&ge; 80%** en el conjunto de prueba.

## Stack Tecnológico
- **Lenguaje**: Python
- **Librerías**: NumPy, Pandas, Matplotlib, Seaborn, scikit-learn.

## Dataset
- **Fuente**: [UCI Weather in Australia](https://www.kaggle.com/datasets/jsphyg/weather-dataset-rattle-package)
- **Variables**: Temperatura, Humedad, Presión, Velocidad del viento, etc.

## Estructura del Proyecto
- `01_Exploracion_y_KNN.ipynb`: Notebook principal de desarrollo.
- `src/`: (Opcional) Scripts de Python para la implementación manual.
- `reports/`: Reporte técnico en formato IEEE.
