# 03: Red Neuronal Manual — MNIST

## Área de Conocimiento
Redes neuronales y fundamentos matemáticos de Deep Learning

## Skills Adquiribles
- Implementación de un Multi-Layer Perceptron (MLP) de dos capas ocultas desde cero usando NumPy.
- Programación manual del forward pass, backpropagation y cálculo de gradientes.
- Uso de funciones de activación (ReLU, Sigmoid) y optimizadores (SGD, momentum).
- Validación de implementaciones manuales contra frameworks maduros como PyTorch.
- **Stack Tecnológico:** Python, NumPy, Matplotlib, PyTorch.
