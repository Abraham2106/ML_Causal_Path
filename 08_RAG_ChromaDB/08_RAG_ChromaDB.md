# 08: Sistema RAG — Asistente de Documentación Técnica

## Área de Conocimiento
Sistemas Retrieval-Augmented Generation (RAG) y Memoria Vectorial

## Skills Adquiribles
- Construcción de un pipeline RAG completo para indexar y recuperar información basada en embeddings semánticos.
- Diseño e implementación de estrategias de "chunking" de documentos y retrievers híbridos.
- Configuración y manejo de bases de datos vectoriales.
- Evaluación automática del sistema RAG utilizando metodologías y métricas de RAGAS (faithfulness, context recall).
- **Stack Tecnológico:** Python, ChromaDB, LangChain, sentence-transformers, RAGAS, Ollama.
