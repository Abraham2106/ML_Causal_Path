# Machine Learning & Causal Inference Roadmap

## Executive Summary
This repository contains a structured, 12-month training and development program transitioning from foundational machine learning algorithms to advanced research in causal inference and Large Language Model (LLM) agents. The primary objective is the development of CausalBench, a specialized benchmark designed to measure causal information loss in LLM agent memory systems.

The program is organized into 12 independent, progressively complex projects. This structure ensures a rigorous progression through classical machine learning, deep learning, NLP, and agentic architectures before culminating in advanced academic research.

## Roadmap Structure

The curriculum is divided into four main phases:

### Phase 1: Machine Learning Foundations (Months 01 - 04)
Focuses on classical machine learning, neural network fundamentals, and basic NLP.
*   **01:** Weather Classifier (K-Nearest Neighbors)
*   **02:** Housing Price Predictor (Linear Regression & Decision Trees)
*   **03:** Manual Neural Network Construction (Multi-Layer Perceptron)
*   **04:** Sentiment Analysis (Classical NLP & Word Embeddings)

### Phase 2: Modern Deep Learning (Months 05 - 06)
Focuses on computer vision and attention mechanisms.
*   **05:** Plant Disease Detection (Convolutional Neural Networks & Transfer Learning)
*   **06:** News Classification (Transformers & BERT Architecture)

### Phase 3: Agents and Memory Systems (Months 07 - 09)
Focuses on LLM agents, retrieval systems, and context compression.
*   **07:** Task Agent with Session Memory
*   **08:** Technical Documentation Assistant (RAG & Vector Databases)
*   **09:** Context Compression Strategy Benchmarking

### Phase 4: Research and Causal Inference (Months 10 - 12)
Focuses on causality, evaluation metric design, and the integrated final system.
*   **10:** Causal Relationship Extraction from Text
*   **11:** Agent Memory Evaluation Benchmarking
*   **12:** Causal Memory System Prototype (Pre-CausalBench)

## Methodology
Each monthly project adheres to a standardized scientific and engineering approach to ensure consistency, reproducibility, and professional documentation habits:
1.  **Theoretical Foundation:** Literature review of essential papers and textbook chapters.
2.  **Implementation:** Development of pipelines, models, and evaluation frameworks.
3.  **Experimentation:** Hyperparameter tuning, ablation studies, and comparative analysis.
4.  **Reporting:** Documentation of methodology, results, and conclusions formatted according to academic standards (IEEE/ACL).

## Evaluation Criteria
Progression through the roadmap requires meeting strict, measurable Key Performance Indicators (KPIs) for each project. A project is considered complete only when:
*   Specific quantitative thresholds (e.g., Accuracy, F1-Score, RMSE, Cohen's Kappa) are achieved.
*   A formal technical report is produced detailing the experiments and results.
*   The codebase is thoroughly documented, reproducible, and committed to the respective project directory.

## Ultimate Goal: CausalBench
The culmination of this 12-month trajectory is the formal proposal and development of CausalBench. This final project integrates the capabilities developed throughout the year, specifically NLP extraction pipelines, RAG systems, context compression strategies, and custom evaluation metrics. The final system is designed to measure and analyze causal reasoning capabilities and information retention within persistent LLM architectures.
